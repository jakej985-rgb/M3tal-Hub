# 03 Idle Animals

## Goal
Release Idle Animals through M3tal-Hub at `/idle-animals/`.

## Steps
1. Confirm the current Flutter project builds.
2. Fix any missing web configuration required for deployment.
3. Configure the application base path.
4. Add the standard dispatch workflow.
5. Add HUB_DISPATCH_TOKEN.
6. Test static assets and save/state behavior.
7. Dispatch a test release.
8. Verify the deployed subdirectory.
9. Enable automatic releases.

## Definition of Done
Idle Animals has a reproducible web build and works from its hub path.
