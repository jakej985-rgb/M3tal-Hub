# 07 Spec-s-N-Part-s

## Goal
Determine whether Spec-s-N-Part-s is a duplicate, predecessor, or separate release from Subaru.specs.n.parts.

## Steps
1. Compare project purpose and source tree with Subaru Specs & Parts.
2. Decide which repository is authoritative.
3. If duplicate, keep this registry entry disabled.
4. If separate, identify its build stack.
5. Add its dispatch workflow only after the decision.
6. Configure its unique hub path if retained.

## Definition of Done
Only the intended Subaru application is released and duplicate projects are not accidentally published.
