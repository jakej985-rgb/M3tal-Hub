# 11 M3tal Plugin Page

## Goal
Release the plugin landing/documentation page through M3tal-Hub.

## Steps
1. Identify the current static site files.
2. Add a deterministic static release directory.
3. Add dispatch workflow.
4. Add HUB_DISPATCH_TOKEN.
5. Register the application path.
6. Test deployment.
7. Enable automatic releases.

## Definition of Done
The plugin page is available from the hub and can be updated by pushing to main.
