# 02 Android Card Games

## Goal
Release the Flutter web build through M3tal-Hub at `/Android-card-games/`.

## Steps
1. Verify Flutter web build.
2. Determine web renderer and output directory.
3. Configure the base path for the hub subdirectory.
4. Add the standard dispatch workflow.
5. Add HUB_DISPATCH_TOKEN.
6. Test navigation and browser refreshes.
7. Verify assets and generated routes.
8. Dispatch a release to M3tal-Hub.
9. Enable automatic release after validation.

## Definition of Done
The web version loads and navigates correctly from its M3tal-Hub subdirectory.
