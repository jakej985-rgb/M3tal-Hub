# 13 Other Application Repositories

## Candidates
- Ink-vault
- Shop-manager
- Tattoo-Shop-manager
- Infernal-Ink-Steel-Suite

## Steps
1. Determine whether each repository is a standalone web application, backend, desktop application, or combined system.
2. Identify its production build output.
3. Decide whether it belongs on GitHub Pages or only needs a release link.
4. Configure a subdirectory only for static/browser applications.
5. Add dispatch integration.
6. Keep backend-only services out of the Pages deployment.
7. Enable each project individually after validation.

## Definition of Done
Every candidate has an explicit deployment classification and is either integrated or intentionally excluded.
