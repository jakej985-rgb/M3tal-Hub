# 12 Munchkin Companion App

## Goal
Prepare the Flutter application for a web release at `/munchkin-companion-app/`.

## Steps
1. Verify the Flutter project is present and builds.
2. Add web support where needed.
3. Configure the hub base path.
4. Add dispatch workflow.
5. Add HUB_DISPATCH_TOKEN.
6. Verify browser storage and routing.
7. Dispatch a test release.
8. Enable automatic releases.

## Definition of Done
A reproducible Flutter web build is available from the M3tal-Hub subdirectory.
