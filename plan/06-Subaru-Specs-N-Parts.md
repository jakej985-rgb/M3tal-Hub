# 06 Subaru Specs & Parts

## Goal
Release Subaru Specs & Parts through M3tal-Hub at `/subaru-specs-n-parts/`.

## Steps
1. Verify Flutter web build.
2. Verify generated SQLite/Drift assets are compatible with web.
3. Configure subdirectory base path.
4. Add dispatch workflow.
5. Add HUB_DISPATCH_TOKEN.
6. Test offline-first behavior in a browser.
7. Verify deep links and asset paths.
8. Dispatch a test release.
9. Enable automatic release.

## Definition of Done
The web application works from the M3tal-Hub subdirectory without breaking its local-data model.
