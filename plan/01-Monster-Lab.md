# 01 Monster Lab

## Goal
Release Monster Lab through M3tal-Hub at `/Monster-Lab/`.

## Steps
1. Confirm Flutter web build works from a clean checkout.
2. Identify the current Flutter web output directory.
3. Configure the app for a subdirectory/base path.
4. Add the standardized M3tal-Hub dispatch workflow.
5. Add the hub dispatch secret.
6. Build and test locally.
7. Dispatch a test release.
8. Verify assets, routing, refreshes, and deep links under `/Monster-Lab/`.
9. Enable automatic releases after successful validation.

## Definition of Done
Monster Lab can be released by pushing to main and works completely from its M3tal-Hub subdirectory.
