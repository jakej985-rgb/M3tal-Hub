📖 Installation & Setup Documentation

Lightweight browser companion extension for 1-click YouTube Music session linkage with your self-hosted Red Music Locker server. Available for Google Chrome and Mozilla Firefox.

System Prerequisites

  • Google Chrome, Chromium, Brave, Microsoft Edge, or Mozilla Firefox
  • Active YouTube Music session on music.youtube.com
  • Running Red Music Locker container instance

Google Chrome / Chromium Extension Installation

1. Download 'red-music-locker-account-linker-chrome-v1.1.0.zip' from GitHub Releases. 2. Extract the ZIP archive into a local folder. 3. Open Chrome and navigate to 'chrome://extensions'. 4. Enable the 'Developer mode' toggle in the upper right corner. 5. Click 'Load unpacked' in the upper left and select the extracted folder containing manifest.json. 6. Pin the Red Music Locker extension icon to your browser toolbar.

# Download Chrome release package from GitHub Releases:
wget https://github.com/jakej985-rgb/red-music-locker-account-linker/releases/download/v1.1.0/red-music-locker-account-linker-chrome-v1.1.0.zip

# Unpack Chrome release package:
unzip red-music-locker-account-linker-chrome-v1.1.0.zip -d chrome-linker/
# In chrome://extensions -> Enable Developer Mode -> Click 'Load unpacked' -> Select chrome-linker/

Mozilla Firefox Add-on Installation

1. Download 'red-music-locker-account-linker-firefox-v1.1.0.zip' from GitHub Releases. 2. Open Firefox and navigate to 'about:debugging#/runtime/this-firefox'. 3. Click 'Load Temporary Add-on...'. 4. Select 'red-music-locker-account-linker-firefox-v1.1.0.zip' or the manifest.json inside it. 5. The extension will appear in your Firefox toolbar ready to link.

# Download Firefox release package from GitHub Releases:
wget https://github.com/jakej985-rgb/red-music-locker-account-linker/releases/download/v1.1.0/red-music-locker-account-linker-firefox-v1.1.0.zip

# In Firefox about:debugging#/runtime/this-firefox:
# Click 'Load Temporary Add-on...' -> Select red-music-locker-account-linker-firefox-v1.1.0.zip

Connect to Red Music Locker Server

1. Navigate to music.youtube.com in your browser and confirm you are signed in. 2. Click the Red Music Locker icon on your browser toolbar. 3. Enter your self-hosted server URL and click 'Link Account'. The extension securely forwards session headers directly to your server.
