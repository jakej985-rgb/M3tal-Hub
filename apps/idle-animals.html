📖 Installation & Setup Documentation

Idle Animals (Extinction Sanctuary) is available across both Android and modern Web browsers, offering instant Progressive Web App (PWA) gameplay with offline persistence alongside a standalone native Android APK release.

System Prerequisites

  • 🌐 Web / PWA: Modern browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari)
  • 🤖 Android: Mobile device running Android 8.0 (API 26 / Oreo) or higher
  • Android setting: 'Install unknown apps' enabled for your browser or file manager
  • 🛠️ Developer: Flutter SDK >= 3.22 and Dart SDK >= 3.4

🌐 Web / PWA Browser Gameplay

1. Play immediately in your browser via M3tal Hub (or visit /M3tal-Hub/Idle-animals/). 2. No installer or download required for direct browser gameplay. 3. To install locally as a standalone Progressive Web App (PWA), tap 'Install App' in your browser address bar or select 'Add to Home Screen' from the browser menu. 4. Service workers automatically cache game assets for complete offline progression.

# Live Web App URL:
https://jakej985-rgb.github.io/M3tal-Hub/Idle-animals/

🤖 Android APK Installation

1. Download the release package extinction-sanctuary-v1.0.0+1.2.apk from GitHub Releases. 2. On your Android device, navigate to Settings > Security / Apps > Special App Access and enable 'Install unknown apps' for your browser or file manager. 3. Open the downloaded extinction-sanctuary-v1.0.0+1.2.apk file and tap 'Install'. 4. Once installed, launch 'Extinction Sanctuary' from your app drawer and enjoy native gameplay.

# Direct APK Download URL:
https://github.com/jakej985-rgb/Idle-animals/releases/download/v1.0.0+1.2/extinction-sanctuary-v1.0.0+1.2.apk

# Or sideload directly via ADB:
adb install -r extinction-sanctuary-v1.0.0+1.2.apk

🛠️ Local Development & Build

Developers can clone the source code to build and test both the Web and Android APK targets locally.

# Clone source repository
git clone https://github.com/jakej985-rgb/Idle-animals.git
cd Idle-animals
flutter pub get

# Run locally in Chrome
flutter run -d chrome

# Run on Android device or emulator
flutter run -d android

# Build production releases
flutter build web --release --base-href /M3tal-Hub/Idle-animals/
flutter build apk --release
