📖 Installation & Setup Documentation

Subaru Specs & Parts is an offline-first technical reference manual and fitment database available as an instant in-browser Progressive Web App (PWA) on M3tal-Hub and as a standalone Android APK package.

System Prerequisites

  • Web PWA: Modern web browser (Chrome, Firefox, Safari, Edge) with Service Worker and IndexedDB support
  • Android APK: Mobile device running Android 8.0 (Oreo / API 26) or higher
  • Developers / Build from Source: Flutter SDK >= 3.24, Java 17, Android Studio / Gradle toolchain

🌐 Instant Web & PWA Installation

1. Open the web application directly from M3tal Hub (https://jakej985-rgb.github.io/M3tal-Hub/subaru-specs-n-parts/). 2. In Chrome or Chromium-based browsers, tap the 'Install App' prompt in the address bar or choose 'Install Subaru Specs & Parts' from the browser menu. 3. The PWA caches engine torque specs, fluid capacities, and chassis dimensions for complete roadside functionality without mobile cell service.

# Web deployment URL:
https://jakej985-rgb.github.io/M3tal-Hub/subaru-specs-n-parts/

📱 Android APK Installation (Alpha Release)

1. Download the Alpha release package 'android-apk.V.A0.1.zip' from the GitHub Releases page. 2. Extract the archive on your Android device or computer to retrieve the .apk package. 3. In Android Settings, enable 'Install unknown apps' for your browser or file manager. 4. Open the extracted APK file to complete installation and launch.

# Direct package download:
curl -LO https://github.com/jakej985-rgb/Subaru.specs.n.parts/releases/download/Alpha/android-apk.V.A0.1.zip
unzip android-apk.V.A0.1.zip

# Or install directly using ADB on connected device:
adb install -r *.apk

🛠️ Compiling from Source

To build the Android APK or web bundle directly from source code:

git clone https://github.com/jakej985-rgb/Subaru.specs.n.parts.git
cd Subaru.specs.n.parts
flutter pub get
flutter test
flutter build apk --release
