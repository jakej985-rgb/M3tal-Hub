📖 Installation & Setup Documentation

Red Music Locker provides a responsive Web frontend for audio streaming and playlist management on M3tal-Hub, paired with a containerized YouTube Music background synchronization service using Docker Compose.

System Prerequisites

  • Modern web browser for instant web player access (Chrome, Firefox, Safari, Edge)
  • Docker Engine >= 24.0 and Docker Compose v2.x for background sync container
  • Host audio directory containing your music collection (FLAC, MP3, AAC)

Web Frontend Player Access

Access the Flutter web audio player directly on M3tal-Hub. The web player connects to your self-hosted instance or runs with client-side audio caching. It can also be installed as a Progressive Web App (PWA) for offline access.

# Direct web access:
https://jakej985-rgb.github.io/M3tal-Hub/red-music-locker/

Docker Sync Container Deployment

Download the release compose specification ytsync.yml and copy default.env.example to .env. Configure your music library mount paths, config directory, and port:

curl -fsSL https://raw.githubusercontent.com/jakej985-rgb/red-music-locker/main/ytsync.yml -o ytsync.yml
curl -fsSL https://raw.githubusercontent.com/jakej985-rgb/red-music-locker/main/.env.example -o .env
# Edit .env to set your MUSIC_PATH, CONFIG_PATH, and PORT

Launch Background Sync Service

Start the containerized sync service in detached mode. The service runs under an unprivileged user with read-only music directory mounts.

docker compose -f ytsync.yml up -d
docker compose -f ytsync.yml ps
docker compose -f ytsync.yml logs -f ytm-sync

Link YouTube Music Account

Use the Red Music Locker Account Linker browser extension or auto-link utility to pair your YouTube Music library session with the self-hosted sync container.
